# Audiophile E-commerce platform for audio devices

Built for HNG 13 frontend stage 3a task.
[Figma File](https://www.figma.com/design/jfDxXzGw2lfyJOgFGbJOW4/audiophile-ecommerce-website?node-id=0-2072&t=MnCkjeksoG1Zo6mk-0)

## Features

- Local state cart storage with context
- DB storage on cart checkout (with convex)
- Email summary on successful checkout (with nodemailer)
- Fully responsive

## Technologies used

- [Next JS](https://nextjs.org/)
- [Convex](https://docs.convex.dev/)
- [Tailwind Css](https://tailwindcss.com/)
- [Nodemailer](https://nodemailer.com/)
- [Typescript](https://www.typescriptlang.org/)
- [React hot toast](https://react-hot-toast.com/)

## ENV variables

- CONVEX_DEPLOYMENT
- NEXT_PUBLIC_CONVEX_URL

## How to run locally

```bash
git clone https://github.com/Moluno-xiii/audiophile_ts_react
cd audiophile_react_ts
pnpm install
pnpm dev
```
